## 🚀 Projetos em destaque

### 🏥 Sistema de Agendamento Médico — QA & Testes

[![Repositório](https://img.shields.io/badge/Ver%20repositório-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/poo-ec-2026-1/g8)

Aplicação desktop para gestão de agendamentos médicos e prontuários, desenvolvida em **Java 17**, com interface **JavaFX**.

**Minha atuação:** responsável por QA e testes, com elaboração do plano de testes, definição de casos e validação das funcionalidades. Também trabalhei com testes unitários usando **JUnit 5**, automação de interface com **TestFX** e testes relacionados à persistência dos dados.

<sub>Java · JavaFX · JUnit 5 · TestFX · Maven</sub>

### 🎯 Vision Tracker V2 — Visão Computacional & IoT

[![Repositório](https://img.shields.io/badge/Ver%20repositório-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Matxxxz/Rastreador_Visao_v2)

Projeto experimental de **visão computacional e telemetria IoT**, com arquitetura distribuída que integra uma aplicação em **Python, OpenCV e PySide6** a um nó embarcado **ESP32**, por meio de comunicação **MQTT** e mensagens em **JSON**.

O projeto explora processamento de imagens, comunicação assíncrona, integração entre software e hardware e validação do fluxo em ambiente simulado.

<sub>Python · OpenCV · PySide6 · C++ · ESP32 · MQTT · JSON · Wokwi</sub>
